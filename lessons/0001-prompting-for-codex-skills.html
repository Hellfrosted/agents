Prompting for Codex skills

Improve the skills in this repository by making their contracts easier to route, execute, and verify—without stripping out safety-critical procedure.

About 8 minutes Grounded in this repository’s mission Sources: Prompting, GPT-5.6 guidance, Build skills

The idea in one sentence

Write a skill like a compact contract: name the desired result first, supply only decision-changing context, protect the few boundaries that matter, and say what proves it is done.

What the official guide says

OpenAI’s Prompting guide says that, for larger or more important tasks, use the parts that matter—goal, context, output, and boundaries—and only the parts that help. Its worked example includes a final check without spelling out every step.

Translate that into a SKILL.md

Repository translation: the official prompt components do not prescribe a skill-file format. This repository uses them as a compact design aid; Build skills supports reusable instructions plus optional references and assets.

ContextName only required files, sources, state, or terms.Moving command matrices and version detail to REFERENCE.md.
OutputSpecify the artifact, verdict, or report shape.Using a short canonical template when the output repeats.
BoundariesState the irreversible, privacy, authorization, or scope limits.Keeping one or two critical rules close to the action they protect.
Final checkName the smallest relevant proof.Making the completion condition observable.

Repository adaptation: lead with the result and keep safety-critical sequencing close to the action it protects. Do not force every skill into a five-field form. Current GPT-5.6 prompt guidance recommends keeping outcome, success, safety, permission, stopping, and validation rules while trimming repeated or irrelevant instruction.

Repository convention: bound repeated work

For a genuinely repeated or persistent workflow, use the repository’s shared bounded-loop protocol: define state, next action, stop condition, human gate, budget, and any applicable failure learning.

Do not add this machinery to a one-shot review skill merely because it sounds rigorous.
